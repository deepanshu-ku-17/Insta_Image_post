# Frontend

This folder contains the frontend of the Insta Post Project built using React.

> The main objective of this project was learning backend development, so the frontend is intentionally simple.

---

## Features

- React Components
- Create Post Form
- Image Upload
- Axios Integration
- Basic Responsive Layout

---

## Tech Stack

- React
- Vite
- Axios
- CSS
- React Router DOM

---

## Installation

```bash
npm install
```

---

## Run Project

```bash
npm run dev
```
